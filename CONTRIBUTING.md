# Contributing to Float

Float is a focused interaction experiment. Changes should make it easier to move a conversation, retain context, or direct attention.

1. Open an issue describing the interaction or bug. Include viewport size and reproduction steps for layout bugs.
2. Fork the repository and make a small, focused change.
3. Run `npm test` and `npm run build`.
4. For interface changes, check pointer and keyboard use, a narrow viewport, and reduced-motion behavior. Include before/after screenshots or a short recording in your pull request.

Keep the canvas free of real customer or meeting content. Preserve visible demo labels until a real AI integration exists. Reuse the shared controls and CSS tokens, and avoid introducing a backend or additional dependencies unless the change needs them.

Please be considerate, direct, and constructive in issues and reviews.
